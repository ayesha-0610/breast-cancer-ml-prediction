# 🧬 Breast Cancer Risk Prediction using Machine Learning

> MSc Bioinformatics Thesis | Jamia Hamdard University | 2025

## 📌 Overview
This project applies machine learning techniques to structured 
healthcare data for early-stage breast cancer risk prediction. 
Three models were built, compared, and evaluated — with a key 
finding that interpretable algorithms outperform complex ones 
in clinical settings.

## 🎯 Key Finding
**Linear Regression outperformed Decision Tree and Random Forest**,
highlighting the value of interpretable models in healthcare 
decision-making.

## 🧪 Models Used
| Model | Accuracy | Notes |
|---|---|---|
| Linear Regression | ✅ Best | Most interpretable |
| Decision Tree | Moderate | Prone to overfitting |
| Random Forest | Good | Less interpretable |

## 🛠️ Tech Stack
- Python (Pandas, NumPy, Scikit-learn)
- Matplotlib, Seaborn
- Jupyter Notebook
- Feature engineering & cross-validation

## 📊 Workflow
1. Data loading & exploration (EDA)
2. Feature correlation analysis
3. Data preprocessing & normalization
4. Model training & cross-validation
5. Performance evaluation (Accuracy, F1, ROC-AUC)
6. Model comparison & visualization

## 📁 Project Structure
- `notebooks/` — Jupyter notebooks with full analysis
- `src/` — Python scripts for preprocessing & modeling
- `results/` — Output plots and model comparison charts
- `report/` — Thesis abstract

## 🔬 Dataset
Wisconsin Breast Cancer Dataset (WBCD) from UCI ML Repository
- 569 samples, 30 features
- Binary classification: Malignant / Benign
